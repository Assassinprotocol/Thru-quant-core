## 1. Executive Summary

The **v1.0.0 release** represents the completion of the five roadmap gates (G0 through G4), elevating Thru Quant Core from an experimental laboratory prototype into a verified **Tier T2 Multi-Operator Sovereign Oracle Architecture**.

### Key Architectural Milestones Delivered:
1. **Oracle v2 On-Chain Median Consensus (`src/v2/oracle_v2.c`):** Multi-operator quorum consensus ($M=3$ of 7 nodes) executing deterministic median aggregation and dynamic Median Absolute Deviation (MAD) outlier rejection directly on-chain within ThruVM compute unit constraints ($< 42$ CU).
2. **Deterministic Q64.64 Math & Hardened Core (`src/thru_math.c`):** Eliminates floating-point non-determinism across pre-chain and on-chain calculation pipelines. Verified across 92 golden vectors and continuous differential fuzzing.
3. **Turnkey Partner & Publisher Ecosystem:** Full Dockerized container stack for external validator operators (`deploy/publisher/`), automated onboarding verification (`scripts/verify_publisher.sh`), and consumer integration harnesses (`tests/test_partner_consumer.ts`).

## 4. Upgrade & Migration Guide (v0.4.0 $\to$ v1.0.0)

1. **Protocol Layout:**
   - Legacy v1 consumers reading 948-byte packed single-publisher state continue to function using `sdk/src/decoder.ts`.
   - New integrations should subscribe to Oracle v2 multi-publisher state via API Gateway `/v2/feeds/latest` or query via TypeScript SDK `OracleV2Client`.
2. **Quorum & Feeds:**
   - Supported asset pairs are strictly Core-6 (`BTCUSDT`, `ETHUSDT`, `SOLUSDT`, `USDTUSD`, `USDCUSD`, `WTHRUUSD`).
   - All quotes incorporate on-chain median values, confidence intervals, and dynamic MAD bounds.
