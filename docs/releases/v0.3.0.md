## 4. Operational Hardening & Reliability Deliverables

1. **Probe Separation (`/health` vs `/ready`):**
   - `GET /health`: Pure liveness probe (HTTP 200) verifying process health.
   - `GET /ready`: Readiness probe verifying feed freshness (< 120s), storage initialization, and zero circuit breaker trip. Returns HTTP 503 if stale or tripped.
2. **Feeder Graceful Shutdown & Correlation:**
   - Traps `SIGINT`/`SIGTERM` to safely terminate pending RPC calls and flush state.
   - Outputs sequence correlation identifiers (`seq=%d`) on every broadcast frame.
3. **Incident Recovery Tooling (`--resume`):**
   - Feeder CLI supports `--resume` mode to construct and sign authorized `ORACLE_INSTR_RESUME` (type 2, 6-byte instruction `020000000200`) without manual hex payload crafting.
4. **Developer Console Telemetry Cockpit:**
   - Real-time `#readyPill` status indicator (`READY` vs `DEGRADED (STALE)` / `TRIPPED`).
   - Dynamic decoder latency indicator (`~4.2µs`).
   - Operational telemetry grid tracking total requests, on-chain updates, RPC failures, stale discards, and breaker trips.
5. **Operator Runbook & Clean Reproduction:**
   - Standard Operating Procedures (SOPs) documented in `docs/runbook.md`.
   - Single-command clean clone reproduction script in `scripts/verify_reproduce.sh`.
   - Continuous Integration via GitHub Actions validating all 14 contract scenarios, simulations, decoder tests, and benchmarks.
